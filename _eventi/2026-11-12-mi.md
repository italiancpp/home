### La sessione

**(Im)Perfect Forwarding: A Practical Guide to Value Categories in C++**

"Each C++ expression is characterized by a type and a value category. C++11 introduced rvalue references and move semantics, making value categories essential to modern C++ — and introducing behavior that sometimes surprises even experienced developers.
  
Today, to write correct and efficient programs, we need to understand how the value category of an expression affects lifetime and copying. Is it safe to take the address of a variable, store it as a member or bind it to a const reference?
This is especially important in generic template code, that must work correctly for all intended inputs, lvalues and rvalues alike.

This talk will explain C++'s value categories from a practical perspective:
- the three primary value categories (lvalue, xvalue, and prvalue)
- where value categories show up in C++ code, especially in templates
- how value categories interact with overload resolution, move construction, copy elision, and perfect forwarding
- how value categories and object lifetimes relate
- how to avoid errors in value category-aware template code"
